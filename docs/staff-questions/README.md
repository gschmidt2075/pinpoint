# Staff Questions

Question forms for staff to fill in, and the log of what's been answered.

## Files

| File | What it is |
|---|---|
| `QUESTION-LOG.md` | Running register — every question, its status, and the answer |
| `Payroll-Questions.docx` | 37 questions on employees, time entry, rates |
| `Vendor-Questions.docx` | 28 questions on vendor setup, insurance, contract rates |

## How to use

1. Open the `.docx`, print it or share the file
2. Staff type answers in the right-hand **ANSWER** column
3. Save and hand the file back
4. Upload it in a Cowork session — the answers get read straight out of the table
   and written into `QUESTION-LOG.md`

Partial answers are fine. Anything left blank stays on the open list.

## Answering

- Don't renumber or reorder rows — answers are matched by question number
- "N/A" is a real answer and better than blank
- The free-text box at the end catches anything the questions missed
